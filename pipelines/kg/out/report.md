## 六、口径与局限

- 实体只来自 `demo/experiments` 中已有的事件材料（正文、阶段时间线、官方通报、评论角度），不引入外部事实。
- 规则模式用关键词与句式切分抽取，稳定但召回有限；大模型模式按同一套 JSON 协议抽取，可显著提升实体、原因与后果的完整性。
- 官方通报的 `status` 沿用材料中的 `official_statement_status`：`clear` 记为 confirmed，其余记为 partial。
- 舆情快照来自实验产出的 `metrics_history.jsonl`，只代表该次仿真的 Agent 统计口径。
